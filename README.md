## 🔴 Este repositorio sigue público a propósito

El generador de firmas de correo de la empresa carga el logotipo desde la URL en crudo de este
repositorio:

```
https://raw.githubusercontent.com/esolis2014/lyansa-assets/refs/heads/main/logo/lyansa-logo-signature.png
```

Archivarlo es inocuo: un repositorio archivado sigue sirviendo sus archivos. **Hacerlo privado o
borrarlo dejaría sin logotipo todas las firmas de correo de la empresa, incluidas las que ya
salieron.** Antes de eso hay que servir ese archivo desde un dominio propio y reapuntar el
generador.
